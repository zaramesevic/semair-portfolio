Real-Time Visual Air
Quality Monitoring System

SEMAIR translates complex micro-climate air pollution data into clear, immediate visual traffic-light alerts for instant environmental awareness.

Goal is to raise awareness of air quality monitoring with intuitive signaling

Target deployment places may include classrooms, public halls and urban micro-zones

Instant optical warning removes the barrier of interpreting raw microgram metrics

How It Works

01 / SENSING

Data Acquisition

Sensors capture ambient air parameters like gas levels and particulate concentration in real time.

02 / PROCESSING

Signal Parsing

Microcontroller processes raw analog/digital signals and calculates AQI thresholds using an exponential smoothing filter.

semair_control.ino 
void evaluateAirQuality(int sensorValue) {
  if (sensorValue <= 50) {
    digitalWrite(PIN_GREEN, HIGH);
    digitalWrite(PIN_YELLOW, LOW);
    digitalWrite(PIN_RED, LOW);
  } else if (sensorValue > 50 && sensorValue <= 100) {
    digitalWrite(PIN_GREEN, LOW);
    digitalWrite(PIN_YELLOW, HIGH);
    digitalWrite(PIN_RED, LOW);
  } else {
    digitalWrite(PIN_GREEN, LOW);
    digitalWrite(PIN_YELLOW, LOW);
    digitalWrite(PIN_RED, HIGH);
  }
}
03 / OUTPUT

Traffic Light Signal

Compares current index against preset health safety boundaries (Green/Yellow/Red). Actuates high-luminance LED indicators instantaneously.

PHYSICAL BEACON

Goals

Core targets and deployment roadmap for the SEMAIR system.

Immediate Cognitive Awareness

Replace numerical particulate charts with an intuitive universal traffic light signal that anyone can interpret at a glance without technical training.

Public & Classroom Deployment

Install compact low-power units in schools, lecture halls, and offices to inform students and staff when room ventilation is required.

Affordable Open Architecture

Built on accessible microcontrollers and modular sensors so academic institutions can easily reproduce, customize, and maintain the hardware.
